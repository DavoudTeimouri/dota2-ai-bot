# Contributing to Dota2 AI Bot

Thank you for considering contributing to the Dota2 AI Bot project! We welcome contributions from the community.

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a branch for your feature or bugfix.
4. Make your changes.
5. Ensure your code follows the existing style and includes appropriate tests (if applicable).
6. Commit your changes and push to your fork.
7. Submit a pull request to the main repository.

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features. When reporting a bug, include:
- Your operating system and Python version.
- Steps to reproduce the issue.
- Any error messages or logs.

## Code Style

We follow the existing code style in the repository. Please try to match it for consistency.
